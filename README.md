# Rohit Subramaniam

Product manager who builds. I write agent skills that take a product idea through the hard questions, into a PRD, and on to a prototype a coding agent can build.

## How I work

```
Problem → Product thinking → PRD → Prototype with a coding agent → Test → Revise
```

Every skill I publish follows this loop. Examples are fictional, so the thinking is visible without any company data.

## Skills

**[rohit-skills](https://github.com/subrro11/rohit-skills)**: agent skills grouped by discipline. Works with Claude, Codex, Cursor and Grok.

| Discipline | Skill | What it does |
|---|---|---|
| product | [Deep Research](https://github.com/subrro11/rohit-skills/tree/main/product/skills/deep-research) | Researches a company or idea (company, competitors, news, trends, frameworks), cites only what it read, and hands the evidence to the PRD |
| product | [PRD Generator and Product Quiz Agent](https://github.com/subrro11/rohit-skills/tree/main/product/skills/prd-generator) | Quizzes you on problem, PMF, north star, goals and prioritisation, then writes the PRD and a prototype prompt |
